## 🛠️ Building & Running

### Prerequisites
- Android Studio Ladybug (or newer)
- Android SDK 36 (compileSdk) / Min SDK 24 (Android 7.0+)
- JDK 17

### Build Debug APK
```bash
./gradlew assembleDebug
```
The output APK will be generated at `app/build/outputs/apk/debug/app-debug.apk`.

### Run Unit Tests
```bash
./gradlew test
```
